## 1. Design Principles & Identity

[cite_start]Website ini mengusung tema **"The Dark Canvas"**—sebuah pendekatan visual ultra-modern, minimalis, dan mewah untuk menampilkan portofolio digital berkualitas tinggi yang menarik perhatian dan mendorong interaksi[cite: 1, 7, 51]. [cite_start]Desain ini berfokus pada kedalaman warna gelap (dark mode), tipografi yang presisi, serta interaksi mikro yang halus untuk mencerminkan keahlian teknis tingkat tinggi[cite: 10, 12].

### 🎨 Color Palette
* [cite_start]**Primary Background:** Deep Charcoal / Near Black (`#0B0B0B` atau `#121212`) — Memberikan efek kedalaman kanvas gelap yang elegan berdasarkan visual halaman[cite: 1, 51].
* **Secondary Background:** Matte Dark Gray (`#1A1A1A`) — Digunakan untuk kontainer kartu proyek atau pemisah section.
* [cite_start]**Text / Foreground Primary:** Crisp White (`#FFFFFF`) — Untuk keterbacaan kontras tinggi pada judul utama[cite: 1].
* [cite_start]**Text Secondary / Muted:** Silver/Slate Gray (`#8A8A8A`) — Untuk sub-judul, deskripsi panjang, dan meta-data[cite: 1].
* [cite_start]**Accent Color:** Cyan / Electric Turquoise (`#00F2FE` atau `#00E5FF`) — Digunakan secara eksklusif untuk elemen interaktif, efek *glow*, dan aksen jalur abstrak seperti pada visual fluid dynamics[cite: 1, 42].

### 🔤 Typography & Grid
* [cite_start]**Headings:** Sans-Serif Geometris / Neo-Grotesque dengan tracking/letter-spacing yang lebar untuk memberikan kesan luas, presisi, dan premium[cite: 1, 10].
* [cite_start]**Body Text:** Monospace atau Clean Sans-Serif untuk memperkuat kesan *creative technologist* dan rigor teknis[cite: 7, 12].
* [cite_start]**Grid Layout:** Menggunakan sistem **Asymmetric Grid** dengan *whitespace* (ruang kosong) yang luas untuk membiarkan setiap elemen visual menarik perhatian penuh[cite: 7].

## 3. UI Components & Detailed Specifications

### 🖥️ Navigation Bar (Sticky Floating Header)

[ FM ]        [ Projects ]  [ Experience ]  [ Certifications ]       [ DOWNLOAD CV ]
* **Behavior:** `backdrop-filter: blur(12px)` dengan latar belakang transparan 80%[cite: 1, 51]. Menempel di atas (*sticky*) saat pengguna melakukan *scroll*.
* **CTA Button:** Border tipis 1px dengan efek *hover fill* solid dan warna teks yang berubah secara kontras (*invert text*).

### 📊 Stats & Experience Section
* **Layout:** 4-kolom grid untuk metrik angka pencapaian[cite: 1]. Angka menggunakan ukuran font tebal dan besar (`text-5xl` atau `text-6xl`) dengan animasi pencatatan bertahap (*counter up*) saat masuk ke dalam *viewport*.
* **Timeline Work:** Menggunakan layout vertikal minimalis[cite: 1]. Sisi kiri menampilkan rentang tahun, sisi kanan menampilkan posisi jabatan, nama instansi, serta detail arsitektur sistem digital yang ditangani[cite: 1, 26, 29].

### 💼 Featured Works Cards (Homepage)
Menampilkan grid preview proyek utama dengan spesifikasi interaksi dinamis:
1.  **Nexus OS:** Area kartu menonjolkan visual perangkat mobile[cite: 1, 35].
2.  **Atelier Monolith:** Struktur grid dengan visual bertekstur arsitektural[cite: 1, 37].
3.  **Liquid Motion:** Menonjolkan interaksi bentuk fluida 3D dengan aksen garis neon bercahaya[cite: 1, 40].
4.  **System Design:** Ilustrasi workspace dan keyboard presisi yang melambangkan skalabilitas sistem pemrograman[cite: 1, 43].

* **Card Interaction:** Saat kursor melakukan *hover* pada kartu proyek, gambar latar belakang akan membesar secara halus (*scale-105*) menggunakan transisi bezier (`transition: all 0.5s ease`), dibarengi perubahan kursor kustom menjadi indikator aksi *"View Project"*.

### 🗂️ Interactive Project Gallery (Halaman Galeri)
* **Filter Tabs:** Menggunakan penanda state aktif[cite: 51]. Tab kategori yang sedang aktif (*ALL, UI/UX, DEVELOPMENT*, atau *BRANDING*) ditandai dengan perubahan warna teks menjadi putih terang atau penambahan garis aksen tipis di bawahnya[cite: 51, 57, 58, 59, 60].
* **Flexible Layout Grid:** Menggabungkan orientasi gambar lanskap monitor data analitik, visualisasi sferis jaringan global, objek geometris 3D, serta panel baris kode backend untuk mempertegas identitas teknis[cite: 51].

## 4. Technical Implementation Notes & Interaction Ideas

Untuk menghidupkan dan mengoptimalkan performa arsitektur desain digital ini, berikut adalah rekomendasi implementasi teknisnya:

* **Frontend Stack:** Next.js (React) dikombinasikan dengan Tailwind CSS untuk manajemen utility class yang presisi dan cepat.
* **Animations & Motion:** Gunakan **Framer Motion** atau **GSAP (GreenSock)** untuk menangani interaksi mikro.
    * *Scroll Trigger:* Elemen teks dan gambar muncul perlahan (*fade-in up*) saat di-scroll untuk memperkuat kesan premium.
    * *Custom Cursor:* Buat kursor lingkaran kecil dinamis yang bereaksi (membesar/berganti warna) ketika menyentuh elemen interaktif atau tautan.
* **3D Elements & Rich Media:** Untuk visual abstrak seperti *Liquid Motion* atau bentuk geometris, gunakan aset gambar pre-rendered berkualitas tinggi dengan kompresi `.webp` atau `.avif` agar performa *loading* web tetap instan dan optimal[cite: 1, 40].
* **API & Backend Integration:** Halaman galeri proyek dapat dihubungkan langsung dengan backend berbasis Golang untuk menarik data proyek, detail teknologi yang digunakan, serta status pengerjaan secara dinamis melalui REST API[cite: 51].
